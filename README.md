# Loghi dei partiti

Questa cartella è vuota di proposito. Il sito funziona anche senza: ogni tessera
mostra un monogramma colorato (es. "FdI", "PD") finché non trovi il file giusto.

## Come aggiungerli

1. Scarica il logo da una fonte legittima — il sito ufficiale del partito, o la pagina
   Wikimedia Commons del partito (spesso taggati per uso editoriale/nominativo:
   verifica sempre la licenza specifica del singolo file prima di usarlo).
2. Salvalo in questa cartella con il nome esatto indicato sotto — SVG preferito,
   PNG come alternativa (il sito prova prima .svg, poi .png automaticamente).
3. Fatto — non serve toccare index.html, style.css o script.js.

|-----------------------|---------------------------------|

Nota: i loghi di partito sono marchi registrati. Un uso editoriale/informativo
in un comparatore politico è la prassi comune (lo fanno anche molte testate),
ma resta responsabilità di chi pubblica il sito verificarne i termini —
non è una valutazione che posso fare al posto tuo.
